# 工作筆記示範

這是一篇示範專案日誌。專案、日期和結果都是為了展示格式而編寫的，並不描述我做過的工作。

## 背景

一個三人讀書小組想把筆記集中放在一處。在這個示範中，目標是把一個資料夾的零散文字整理成一個帶目錄的小型 Markdown 網站，我負責搭建檔案結構並檢查最終頁面。

## 進展

- 第 1 週 — 清點現有檔案，確定每個主題一個資料夾。
- 第 2 週 — 加入統一的頁面範本，轉換了前 3 篇筆記。
- 第 3 週 — 與另外兩名成員一起檢查目錄連結，修復了 6 個失效錨點。

## 結果

示範網站可以建置出 12 個頁面，站內連結沒有失效項目。剩下的風險是聊天紀錄裡的舊連結可能指向已經改名的檔案。

## 下一步

- 增加一頁簡短說明，介紹小組如何維護這些筆記。
- 一個月後歸檔原始文字檔案。
