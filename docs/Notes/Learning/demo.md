# Learning notes demo

This is a sample learning note, not a record of my own study. It uses one common question to show what a learning note can look like.

## The question

Why does a prism split white light into colors?

## What the example explains

Glass bends light by an amount that depends on wavelength: shorter wavelengths travel more slowly in glass, so blue light bends more than red. This wavelength dependence is called dispersion and is written as $n = n(\lambda)$. A prism sends each color in a slightly different direction, and the colors separate.

## Common points of confusion

Dispersion is easy to confuse with scattering. In dispersion, the refractive index changes with wavelength; in scattering, particles redirect light. A prism shows the first effect, not the second.

## Next step

Compare the spectrum from a prism with the spectrum from a diffraction grating, where the colors appear in a different order.
