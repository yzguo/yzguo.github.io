# 工作笔记演示

这是一篇示例项目日志。项目、日期和结果都是为了展示格式而编写的，并不描述我做过的工作。

## 背景

一个三人读书小组想把笔记集中放在一处。在这个示例中，目标是把一文件夹的零散文本整理成一个带目录的小型 Markdown 站点，我负责搭建文件结构并检查最终页面。

## 进展

- 第 1 周 — 清点现有文件，确定每个主题一个文件夹。
- 第 2 周 — 添加统一的页面模板，转换了前 3 篇笔记。
- 第 3 周 — 与另外两名成员一起检查目录链接，修复了 6 个失效锚点。

## 结果

示例站点可以构建出 12 个页面，站内链接没有失效项。剩下的风险是聊天记录里的旧链接可能指向已经改名的文件。

- 一个月后归档原始文本文件。
