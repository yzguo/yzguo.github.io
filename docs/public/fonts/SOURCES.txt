Self-hosted font assets
=======================

All fonts below are served from this origin under /fonts/. No third-party font
CDN or system font is required for the site's typography. Full license texts
are stored next to the font files.

Latin Modern Mono 10 (regular, italic)
  Version: Latin Modern 2.005 (2021-03-21)
  License: GUST Font License 1.0 (see latin-modern/GUST-FONT-LICENSE.txt and
           latin-modern/LPPL-1.3c.txt)
  Upstream: https://www.gust.org.pl/projects/e-foundry/latin-modern/
  Source files: https://mirrors.ctan.org/fonts/lm/fonts/opentype/public/lm/
  Modification: converted from OpenType (CFF) to WOFF2; outlines unchanged.
  Scope: code and preformatted text only. The Latin Modern Roman faces were
  removed when body text switched to the local Noto Sans SC faces, so those
  WOFF2 files and @font-face rules no longer exist.

Noto Sans SC
  Version: Google Fonts v41 variable font (weights 100-900)
  License: SIL Open Font License 1.1 (see noto-sans-sc/OFL.txt)
  Upstream: https://fonts.google.com/noto/specimen/Noto+Sans+SC
  Files: 4 merged tier WOFF2 files plus 98 fallback WOFF2 unicode-range slices.
  Tiering: tier1 contains every character used by the current site, the 1,000
  most frequent modern Chinese characters, and CJK punctuation/fullwidth forms;
  tier2 holds frequency ranks 1,001-3,500; tier3 holds ranks 3,501-7,000; the
  symbols tier holds the GB2312 symbol rows (Greek, Cyrillic, kana, punctuation,
  etc.). Character ranks come from the Jun Da Modern Chinese Character Frequency
  List as distributed by hanziDB.csv (MIT).
  Fallback: all 100 original Google Fonts unicode-range slices are retained in
  the build except slices 089/095, whose entire ranges are covered by the tiers.
  Their ranges are narrowed to remove tier characters, so a tier character never
  triggers a fallback download. No previously supported character was dropped.
  Modification: two CSS families are built from these same local slices.
  'Noto Sans SC Latin' is first in the site stack and declares the real Latin
  text ranges present in slices 101 (Basic Latin, Latin-1, punctuation), 100
  (Latin Extended-A/B and pinyin tone letters) and 099 (Vietnamese). It also
  contains punctuation, digits and ©/®/™, but deliberately omits emoji
  pictographs, ZWJ and PUA so those keep the icon/emoji faces that follow.
  'Noto Sans SC' carries CJK, kana, Hangul, fullwidth forms and the symbol
  tiers; its Latin-letter ranges are still excluded, so Latin text always
  resolves to the Latin family. Both families are self-hosted; no CDN or
  system font is involved.
  Subsets were generated from the variable font and retain the 100-900 axis.

Noto Emoji
  Version: Google Fonts v65, monochrome
  License: SIL Open Font License 1.1 (see noto-emoji/OFL.txt)
  Upstream: https://fonts.google.com/noto/specimen/Noto+Emoji
  Files: one static-weight (400) WOFF2 containing the emoji codepoints in the
  Noto Emoji cmap plus keycap bases (1,420 code points, including ZWJ/VS16/
  modifier and keycap codepoints).
  Why: Symbols Nerd Font 3.4.0 contains no emoji codepoints; this font is the
  local emoji supplement.
  Scope: default-presentation emoji (😀, flags, ZWJ sequences) use this monochrome
  face. Chromium does not use it for VS16 emoji presentation or keycap sequences;
  the local Twemoji color face below is the fallback for those. ASCII keycap bases
  are present in the cmap, but ordinary digits use the Noto Sans SC Latin faces,
  which precede this family in the stack.

Twemoji Mozilla
  Version: 0.7.0, COLR/CPAL color font
  License: emoji art CC BY 4.0 (see twemoji/LICENSE.md and
           twemoji/CC-BY-4.0.txt); build code Apache 2.0 (see LICENSE.md)
  Upstream: https://github.com/mozilla/twemoji-colr/releases/tag/v0.7.0
  Files: one WOFF2 (493,484 bytes), exactly the 1,418 codepoints in its cmap.
  Why: Chromium ignores the monochrome Noto Emoji face for VS16 emoji
  presentation and keycap sequences and otherwise selects the system color emoji
  font. Twemoji is placed after Noto Emoji in the stack, so default emoji remain
  monochrome Noto while ©️/❤️/1️⃣/#️⃣ use this local color face. Plain © and
  digits are rendered by the Noto Sans SC Latin faces first.

Symbols Nerd Font
  Version: Nerd Fonts 3.4.0
  License: MIT (see nerd-fonts/LICENSE)
  Upstream: https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.4.0
  Modification: converted from TTF to WOFF2; outlines unchanged.
  unicode-range is limited to the icon codepoints actually present in the font
  (private-use ranges plus 14 legacy symbols), so it never covers body text.
